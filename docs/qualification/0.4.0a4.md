## 3. Public Python and HTTP boundaries

```text
Python caller
  -> PySRMKit.suppliers.search(...)
  -> SupplierSearchService Port
  -> InMemory / SQLAlchemy adapter

Opt-in HTTP caller
  -> GET /suppliers/search
  -> FastAPI transport / validation
  -> PySRMKit.suppliers.search(...)
  -> SupplierPageResponse JSON

Existing Next.js dashboard
  -> GET /suppliers?query=...
  -> legacy Python-side multi-field search
  -> PySRMKit.suppliers.list(...)
```

**Canonical HTTP:** case-insensitive ASCII text search on legal/trading
names only, separate exact country and supplier-type filters, stable
legal-name / UUID sorting and filtered totals before pagination. It
uses FastAPI HTTP validation and maps public DTO `ValueError` to
HTTP 422. Default HTTP page size is 25, versus 100 for Python.

**Legacy HTTP:** retains its independent query semantics, including
matching supplier type, country and external vendor codes and UUID
listing order. It has **not** been silently replaced by canonical
search. The external Next.js dashboard continues to call this route.

## 4. Regression and consumer isolation

A4-05 guards five page boundaries, invalid parameter/error behavior,
and immutable/read-only results across **independently constructed**
InMemory and SQLite stores. This is a test of separate composition
roots and databases; it does **not** constitute a multi-tenant
authorization or access-control security guarantee.

A4-03 qualifies PostgreSQL durable reads after a new runtime
composition, while A4-04 qualifies real browser usage after login,
including vendor code `SUP-008`, country `FI`, name search, clearing
and refresh. Dashboard code was inspected but **not modified**.

## 5. Known limits and decisions

- The Unicode portability contract is still **ASCII-scoped**:
  `casefold()` and DB `lower()` may differ, depending on locale and
  collation. No Unicode equivalence is claimed.
- SQL query plans in A3 were observed with synthetic data. A4 adds no
  query indexes, migrations or production performance guarantees.
- The legacy HTTP full-set scan can be expensive at scale and remains
  a compatibility behavior, not a recommended high-volume search API.
- The FastAPI host is an optional example, **not** a mandatory runtime
  dependency or part of the core Supplier Domain.
- Dashboard CI currently checks out the external repository's
  default branch. Without a pinned SHA, the evidence supports the
  tested revision only, not every future dashboard commit.
- No Git tag, GitHub Release or PyPI publication is established by
  source-level CI qualification alone.

## 7. Software design learning

**Ports & Adapters / DIP:** consumers use public Facade contracts while
HTTP/database remain boundary adapters. **Contract Testing** proves
observable equivalence when the actual contracts agree;
**Characterization Testing** records intentional legacy differences.
**Anti-Corruption Layer** separates HTTP validation/serialization
from business logic. **CQS** and immutable Views protect read-side
semantics. **Expand-and-Contract** evolves the HTTP surface additively.
**SoC, KISS, YAGNI** avoid a speculative HTTP migration or extra
generic abstraction.
