## Reproducibility boundaries

- The external dashboard source is pinned and its SHA is asserted, but the overall integration is **not hermetic**: runner image, action versions, package resolution, and the PostgreSQL image tag can change.
- Sequential repeated bootstrap demonstrates idempotence under the tested conditions, not concurrent bootstrap safety, crash recovery or idempotence of externally owned Next.js seeding.
- The stack runner tests child process cleanup after modeled failures, not complete process-tree/descendant termination or arbitrary signal/crash resilience.
- Unicode search portability is guaranteed for the documented ASCII contract only; non-ASCII matching/collation remains backend-specific.
- Query explain plans on a 1,200-row synthetic corpus are diagnostics, not latency SLAs or an index recommendation.
- Optional FastAPI/Next.js integrations are not mandatory dependencies of the Supplier Domain framework.
- CI passing is not a security audit, production readiness certificate, Git tag, GitHub Release or PyPI publication.

## Software design reasoning

**Contract Testing / LSP:** compare supported adapters and consumers through explicit guarantees, without pretending intentionally different interfaces are identical. **Dependency Pinning and reproducibility:** replace floating source input with exact source revision. **Exception Safety and resource ownership:** protect cleanup through context manager boundaries. **Idempotency:** verify observable state across repeated executions. **Evidence-Based Design, SoC, KISS, YAGNI:** document known limits, avoid unrelated domain changes, migrations, indexes or speculative reliability claims.
