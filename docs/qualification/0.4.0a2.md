- **A2-04:** public `SuppliersAPI.search()` facade.

## Behavioral acceptance

- Read-only Supplier discovery through `PySRMKit.in_memory()` and
  `PySRMKit.sql(engine)`.
- Partial searches in legal or trading name, ordinary ASCII case insensitivity,
  exact country and supplier-type filters.
- Sorted by case-insensitive `legal_name`, then ascending Supplier UUID for
  ties, including descending-name requests.
- `total` after filtering and before pagination, `offset >= 0`,
  `1 <= limit <= 100`; empty results and partial final pages.
- SQL wildcard characters `%` and `_` interpreted literally.
- Immutable `SupplierPageView`, no query-side Domain Events or Aggregate mutation.
- Original `suppliers.list()` remains available with its original UUID order,
  signature and return type.
- No mandatory dependency added to core package metadata.

## Qualification scope and caveats

The new shared behavioral search tests run against **InMemory and SQLite**.
The CI `postgresql` job is green, but that job does not yet run the new
search contract suite against PostgreSQL. Similarly, the `integration` job
validates the existing FastAPI/Next.js demonstration stack but does not by
itself certify all cross-consumer search semantics.

Unicode normalization, accents and `casefold` parity are **not** guaranteed
between Python, SQLite and PostgreSQL: native SQL case conversion and collations
may disagree. Do not claim a strict three-adapter equivalent search contract at
this milestone.

External-identifier search, full-text indexing, relevance ranking and fuzzy
matching are outside the `0.4.0a2` public contract.

## Design principles exercised

- **Command-Query Separation** - reads are non-mutating.
- **Interface Segregation** - optional search port does not break list-only adapters.
- **Dependency Inversion / Ports & Adapters** - public handler depends on a Protocol.
- **Facade / Immutable DTO / Immutable Views** - consumer API is Python-first and stable.
- **Composition Root / Transaction Boundary** - wiring belongs to runtime adapters.
- **Contract Testing / Liskov Substitution** - repeated common behavior is tested
  without assuming already-proven three-backend Unicode equivalence.
- **KISS / YAGNI** - no speculative external search engine.

## Next milestone
