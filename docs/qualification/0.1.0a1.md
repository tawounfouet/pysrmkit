## Bootstrap retrospective

### Did the src layout work?

Yes. Editable installation builds and imports the installed package correctly.

### Were the architecture rules executable?

Yes. The isolated architecture drill demonstrated that a forbidden inward dependency is detected.

### Did configuration remain simple?

Yes. Package, Pytest, Coverage, Ruff, and Pyright configuration are centralized in `pyproject.toml`.

### Was any configuration speculative?

No infrastructure framework, database configuration, broker configuration, cloud configuration, or external connector was introduced.

### Adjustment discovered from real execution

Ruff's formatter also inspects Python examples inside Markdown documentation. Because the specification baseline is intentionally frozen, `docs/` was excluded from Ruff formatting while `src/` and `tests/` remain fully checked.

This is an implementation-discovered adjustment rather than a speculative architectural decision.
